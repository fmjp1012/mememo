# 簿記教材カリキュラム方針

ブラウザ版 ChatGPT Pro で作成した構成案を、Mememo の既存問題・復習機能へ接続するための実装方針です。

## 学習体験

教材は問題集の代わりではなく、問題を解く前の短い理解レイヤーとします。

1. 5〜10分で要点を読む
2. 具体例・仕訳例で確認する
3. 1問の理解チェックに答える
4. 教材に紐づく問題を5問解く
5. 後日、既存の復習キューで定着させる

教材進捗は問題の正誤・復習進捗と分けて保存します。既存ユーザーには前提レッスンによる強制ロックをかけず、次に学ぶ教材を推薦します。

## コンテンツ品質基準

- 1レッスンにつき到達目標を3つ前後に絞る
- 要点は3〜5点、例は1〜2個、よくある間違いは1〜3個にする
- 仕訳は借方・貸方・勘定科目・金額を構造化して表示する
- 理解チェックには正解だけでなく判断理由を付ける
- 状態は未学習・学習中・理解済み・要復習・定着を区別し、色だけに依存しない
- 教材と問題の対応は `relatedQuestionFilters` で明示する

## 今日の学習との接続

「今日」画面に未完了の次レッスンを1件だけ表示します。教材を完了した後は関連問題5問へ直接進めます。問題の1日上限と教材進捗は別に管理し、既存の Anki 風復習キューを維持します。
